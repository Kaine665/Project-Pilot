# Windows 安装包：SmartScreen /「无法确认发布者」/ 智能应用控制

## 原因

从 **GitHub Releases**、**PR 预发布** 或 Actions Artifact 下载的 **ProjectPilot 安装包（`.exe`）** 当前 **未使用 Authenticode 证书签名**（仓库里 `electron-builder` 配置为 `signAndEditExecutable: false`，CI 也未注入签名密钥）。

PR 预发布构建的安装包文件名已改为简短形式（如 `ProjectPilot-PR80-b12345.exe`），**应用内版本号**仍为完整 semver 预发布串；文件名本身**不能替代**代码签名，但可避免默认的 `ProjectPilot Setup 0.1.x-pr…` 过长、含空格与多段点号带来的观感问题。

微软 **SmartScreen** 对「从互联网下载 + 无信誉签名」的可执行文件会提示 **「Windows 已保护你的电脑」** 或 **「无法验证发布者」**，属于**正常策略**，不代表安装包已被篡改。

## 自行安装 / 内测时怎么做（信任来源的前提下）

1. **SmartScreen 蓝色拦截页**  
   点 **「更多信息」**（或「仍要运行」类按钮）→ **「仍要运行」**，再按安装向导操作。

2. **已下载的 `.exe` 仍被拦截**  
   在资源管理器中 **右键 → 属性** → 若底部有 **「安全：此文件来自其他计算机…」**，勾选 **「解除锁定」** → 应用 → 再双击运行。

3. **企业环境**  
   若组策略禁止未签名安装，需由管理员放行或使用已签名的发行版。

## 安装好了，但运行时说「智能应用控制系统阻止了」

这是 **Windows 11 的「智能应用控制」（Smart App Control）**，和安装阶段的 **SmartScreen** 不是同一件事：安装程序跑完后，**启动 ProjectPilot.exe** 时系统再拦一层——当前 CI 打的 **主程序未做代码签名**，在「智能应用控制」为 **开启** 时，很容易被归为「未受信任」而**禁止运行**。

### 个人电脑可尝试（自担风险、信任来源的前提下）

1. 打开 **设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制**（若菜单略有出入，可在设置里搜索 **「智能应用控制」**）。  
2. 将模式改为 **「评估」**（只观察、多给提示）或按界面说明 **关闭**（部分版本对「关闭」有条件，以系统显示为准）。  
3. 改完后 **重新启动应用**；若仍被拦，可 **重启电脑** 再试。

**公司 / 学校电脑** 上该项常由 **组策略锁定**，你可能 **没有修改权限**，只能找 **IT** 放行或等 **带 Authenticode 签名的正式安装包**。

### 长期

与上文 **代码签名** 一致：对公网用户要减少「装完又拦」，需要 **购买证书并为 exe 签名**；仅靠改名或关系统功能不是产品级方案。

## 没有「仍要运行」、界面直接拒绝（硬拦截）

有时 **不会出现「更多信息」**，或点完仍无法运行，常见原因与可试办法如下（**仍须你确认文件来源可信**）：

### 先确认环境

- **公司 / 学校电脑**：可能开了 **WDAC / AppLocker / 软件限制策略**，未签名 exe **一律禁止**，用户侧**没有放行权**，只能找 **IT 加白名单** 或等 **正式签名版**。
- **Windows 11「S 模式」**：只能装 Microsoft Store 应用，**任意下载的 .exe 都可能被系统挡死**。需在 **设置 → 系统 → 激活 / 关于** 里查看是否在 S 模式；若在，需按微软说明 **退出 S 模式**（一次性、不可逆）后再装桌面软件。
- **家庭账号家长控制**：可能禁止安装未知来源应用，需在家长端放行。

### 仍可操作时（个人电脑、无上述策略）

1. **先去掉「从网络下载」标记（推荐先试）**  
   用 **PowerShell** 进入安装包所在文件夹执行（路径改成你的实际文件名）：
   ```powershell
   Unblock-File -LiteralPath ".\ProjectPilot Setup x.x.x.exe"
   ```
   再在资源管理器里 **右键 → 属性**，若有 **「解除锁定」**，勾选并应用，然后再双击。

2. **换获取方式（减少「网络下载」标记）**  
   例如让同事用 **U 盘** 拷给你（同一文件、不经浏览器下载），有时策略会宽松一些（不保证）。

3. **临时放宽 SmartScreen（仅个人机、自担风险）**  
   **设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 基于声誉的保护 → 基于声誉的应用和文件下载**  
   可尝试改为 **警告** 或短时 **关闭**（装完再开回去）。**会降低防护**，仅作权宜之计。

若以上都做不了、仍无任何「仍要运行」，**基本可判定为策略或 S 模式硬挡**，只能 **换非管控电脑测试**、**IT 放行** 或 **项目方购买证书签名后再发版**。

## 与「正式产品」相关的长期方案

要让 SmartScreen **默认不拦**或明显减少提示，需要 **购买代码签名证书** 并在构建时签名，例如：

- **标准 OV 证书**：签名后仍可能需一定下载量积累「信誉」；
- **EV 证书**：通常更快获得 SmartScreen 信任，成本与审核更高。

实现上可在 **`electron-builder`** 中配置 `win.certificateFile` / `certificatePassword`（或 `CSC_LINK` + `CSC_KEY_PASSWORD`），在 **GitHub Actions** 里用 **Secrets** 注入证书（勿提交仓库）。

维护者评估成本与发版节奏后再启用签名即可；在此之前，上述用户侧步骤是预期行为。
