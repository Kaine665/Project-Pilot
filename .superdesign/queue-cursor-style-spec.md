# 等待消息队列 — Cursor 风格设计规范

## Cursor 的做法（参考）

根据 Cursor 官方文档和社区反馈：

1. **每条消息单独展示**：不是只显示「N 条排队」，而是每条待发消息都有独立卡片
2. **内容预览**：显示消息文本（或截断预览）
3. **立即发送**：上箭头按钮，将当前消息提前发送（打断当前回复）
4. **删除**：垃圾桶按钮，从队列中移除该消息
5. **编辑**：点击消息内容可编辑，修改后再排队
6. **拖拽排序**：可拖拽调整发送顺序（Cursor 官方文档）

## ProjectPilot 当前实现

- `pendingUserMessagesRef`: `Array<{ text, images, targetSessionId }>`
- 只渲染：`Queued {count} message(s). They will send automatically after current reply.`
- 无单条展示、无操作按钮

## 目标 UI 设计

### 队列区域结构

```
┌─────────────────────────────────────────────────────────────┐
│ 排队中的消息 (2) — 当前回复结束后自动发送                      │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────┐     │
│ │ 1. 帮我再加一个单元测试                    [↑] [🗑]  │     │
│ └─────────────────────────────────────────────────────┘     │
│ ┌─────────────────────────────────────────────────────┐     │
│ │ 2. 顺便检查一下边界情况                    [↑] [🗑]  │     │
│ └─────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────┘
```

### 单条消息卡片

- **内容**：文本预览（可截断，如 80 字），可点击进入编辑
- **序号**：1、2、3...
- **操作**：
  - `[↑]` 立即发送（Send now）— 打断当前 AI 回复，立即发送该条
  - `[🗑]` 删除 — 从队列移除
- **样式**：与「AI is planning」一致的 blue 系，或 zinc 卡片 + blue 强调

### 实现状态（已完成）

- `pendingUserMessages` 状态：与 ref 同步，用于渲染
- `handleSendNow(index)`：停止当前流，取出该条立即发送
- `handleRemoveFromQueue(index)`：从队列移除
- 编辑：暂未实现（可后续扩展）
