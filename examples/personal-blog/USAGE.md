# 如何使用示例项目录制 Demo

## 方法一：手动创建（推荐用于录制）

这种方法更适合录制 demo，因为可以展示实际操作流程。

### 准备工作

1. 启动 ProjectPilot
   ```bash
   npm run dev
   ```

2. 访问 http://localhost:4000

### 录制脚本

按照以下步骤操作，整个过程控制在 **60 秒内**：

#### 场景 1：创建 Flow（10 秒）

1. 点击 "创建新 Flow"
2. 输入名称：`个人技术博客开发`
3. 输入描述：`从零开始开发一个 Next.js 博客`
4. 保存

#### 场景 2：添加任务节点（10 秒）

1. 在 Flow 中点击 "添加节点"
2. 节点名称：`项目初始化`
3. 添加第一个任务：`创建 Next.js 项目并配置基础设置`

#### 场景 3：启动 AI Agent（5 秒）

1. 点击任务旁边的 "开始执行"
2. 等待 AI 开始处理

#### 场景 4：展示 AI 工作流程（30 秒）

**镜头重点**：
- AI 对话窗口（展示理解过程）
- 右侧产物面板（展示提取的 Understanding）
- 计划卡片（展示生成的执行计划）
- 执行状态（如果有）

#### 场景 5：展示结果（5 秒）

- 展示完成的任务状态
- 展示生成的产物

## 方法二：导入示例数据（快速预览）

如果只是想快速看效果，可以导入预制数据。

### 导入步骤

1. **复制示例数据**
   ```bash
   cp examples/personal-blog/demo-data.json data/flows/demo-blog.json
   ```

2. **重启应用**
   ```bash
   # Ctrl+C 停止，然后重新启动
   npm run dev
   ```

3. **查看示例项目**
   - 在 Flows 页面可以看到 "个人技术博客开发"
   - 点击进入查看完整的项目结构
   - 查看已完成的任务和 Session

## 录制技巧

### 推荐工具

**Windows**:
- [ScreenToGif](https://www.screentogif.com/) - 免费，功能强大
- [ShareX](https://getsharex.com/) - 开源，支持录屏和截图

**macOS**:
- [Kap](https://getkap.co/) - 开源，界面简洁
- [Gifox](https://gifox.app/) - 付费但体验很好

**在线工具**:
- [Loom](https://www.loom.com/) - 录制视频，可自动生成 GIF
- [CloudApp](https://www.getcloudapp.com/) - 截图和录屏

### 录制设置

- **分辨率**: 1920x1080 或 1280x720
- **帧率**: 10-15 FPS（GIF 的话）
- **时长**: 30-60 秒（太长用户不会看完）
- **文件大小**: < 5MB（GitHub README 最好不超过 10MB）

### 录制前检查清单

- [ ] 清理浏览器书签栏（看起来干净）
- [ ] 关闭不相关的标签页
- [ ] 调整窗口大小（不要全屏，留点边距更美观）
- [ ] 准备好要演示的内容
- [ ] 测试一遍流程，确保流畅

### 录制要点

1. **开头 3 秒很关键**
   - 直接展示界面，不要浪费时间在加载页面
   - 可以从已经打开的页面开始

2. **突出核心价值**
   - Flow 可视化管理
   - AI 自动执行
   - 产物实时展示

3. **操作要流畅**
   - 鼠标移动不要太快
   - 停顿 1-2 秒让观众看清楚
   - 避免反复修改（提前准备好文案）

4. **结尾要有亮点**
   - 展示最终结果（完成的任务）
   - 展示 AI 生成的产物
   - 可以加一个 "Try it yourself" 的文案

## 后期处理

### 视频转 GIF

如果录制的是 MP4，可以用这些工具转换：

```bash
# 使用 ffmpeg（需要先安装）
ffmpeg -i demo.mp4 -vf "fps=10,scale=1280:-1:flags=lanczos" -gifflags +transdiff -y demo.gif

# 压缩 GIF
gifsicle -O3 --lossy=80 demo.gif -o demo-optimized.gif
```

在线工具：
- https://ezgif.com/ - 视频转 GIF，支持压缩
- https://gifcompressor.com/ - GIF 压缩

## 常见问题

**Q: Demo 太长怎么办？**
A: 剪辑掉中间等待的部分，加速播放某些步骤，只保留关键帧。

**Q: 文字说明放在哪里？**
A: 使用视频编辑工具（如 DaVinci Resolve 免费版）添加字幕，或者直接在 README 中用文字说明。

**Q: 需要配音吗？**
A: GIF 没有声音，但如果做 YouTube 视频，建议配上简单的背景音乐或解说。

**Q: Demo 里的数据要真实吗？**
A: 不需要，但要看起来合理、易懂。避免使用真实的敏感信息。
