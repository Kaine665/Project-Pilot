# 示例项目：个人技术博客开发

这是一个完整的示例项目，展示如何使用 ProjectPilot 管理一个真实的软件开发项目。

## 项目概述

**目标**：从零开始开发一个个人技术博客网站

**技术栈**：Next.js + Markdown + Tailwind CSS

**项目特点**：
- 完整的开发流程展示
- 从需求分析到部署上线
- 包含多个典型开发任务
- 展示 AI Agent 如何辅助开发

## Flow 结构

```
个人博客开发
├── 1. 项目初始化
│   ├── 创建 Next.js 项目
│   ├── 配置 Tailwind CSS
│   └── 设置项目结构
├── 2. 核心功能开发
│   ├── 实现文章列表页
│   ├── 实现文章详情页
│   ├── 添加 Markdown 渲染
│   └── 实现标签系统
├── 3. 美化和优化
│   ├── 设计响应式布局
│   ├── 添加暗色模式
│   ├── 优化 SEO
│   └── 性能优化
└── 4. 部署上线
    ├── 配置 Vercel 部署
    ├── 配置自定义域名
    └── 设置 Google Analytics
```

## 使用方法

1. 导入示例数据到 ProjectPilot
2. 查看各个 Task 的执行过程
3. 观察 AI Agent 如何理解需求、制定计划、执行任务

## 学习要点

- **Phase 1-2**: 看 AI 如何理解开发任务的四要素
- **Phase 3**: 看 AI 如何制定详细的执行计划
- **Phase 4**: 看 AI 如何实际编写代码和配置
- **Phase 5**: 看 AI 如何总结完成情况

## 预期效果

完成这个项目后，你将拥有一个功能完整的个人博客，并且了解了如何用 ProjectPilot 管理整个开发过程。
